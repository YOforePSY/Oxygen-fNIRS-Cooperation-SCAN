# Data dictionary

## example_behavior_data.csv

| Variable | Description |
|---|---|
| dyad_id | Anonymous dyad identifier |
| order_group | Counterbalancing order group |
| Trust_mean_z | Standardized mean interpersonal trust score of the dyad |
| success_gain_z | Standardized change in cooperation success rate |
| efficiency_gain_z | Standardized change in cooperation efficiency |
| age_mean_z | Standardized mean age of the dyad |
| sex_code | Sex code used as a covariate |

## example_ibs_roi_data.csv

| Variable | Description |
|---|---|
| dyad_id | Anonymous dyad identifier |
| Coop_mPFC_Change_z | Standardized change in cooperation-related mPFC inter-brain synchrony |
| Coop_L_DLPFC_Change_z | Standardized change in cooperation-related left DLPFC inter-brain synchrony |
| Coop_R_DLPFC_Change_z | Standardized change in cooperation-related right DLPFC inter-brain synchrony |
| Coop_L_vlPFC_Change_z | Standardized change in cooperation-related left vlPFC inter-brain synchrony |
| Coop_R_vlPFC_Change_z | Standardized change in cooperation-related right vlPFC inter-brain synchrony |
| TaskDiff_mPFC_Change_z | Standardized change in task-difference mPFC inter-brain synchrony |
