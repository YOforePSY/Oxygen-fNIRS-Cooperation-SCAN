# Data dictionary

| Variable | Description |
|---|---|
| dyad_id | Anonymized dyad identifier |
| order_group | Counterbalanced intervention order group |
| Trust_mean | Mean interpersonal trust score of the dyad |
| Trust_mean_z | Standardized dyad-level interpersonal trust score |
| Coop_mPFC_Change_z | Standardized change in cooperation-related mPFC inter-brain synchrony |
| success_gain_z | Standardized hyperbaric-oxygen-related gain in cooperation success rate |
| efficiency_gain_z | Standardized hyperbaric-oxygen-related gain in cooperation efficiency |
| age_mean_z | Standardized mean age of the dyad |
| sex_code | Sex covariate coding used in the analysis |
| Coop_L_DLPFC_Change_z | Standardized change in cooperation-related left DLPFC inter-brain synchrony |
| Coop_R_DLPFC_Change_z | Standardized change in cooperation-related right DLPFC inter-brain synchrony |
| Coop_L_vlPFC_Change_z | Standardized change in cooperation-related left vlPFC inter-brain synchrony |
| Coop_R_vlPFC_Change_z | Standardized change in cooperation-related right vlPFC inter-brain synchrony |
| Coop_L_STC_Change_z | Standardized change in cooperation-related left STC inter-brain synchrony |
| Coop_R_STC_Change_z | Standardized change in cooperation-related right STC inter-brain synchrony |
| Coop_L_SFC_Change_z | Standardized change in cooperation-related left SFC inter-brain synchrony |
| Coop_R_SFC_Change_z | Standardized change in cooperation-related right SFC inter-brain synchrony |
| TaskDiff_mPFC_Change_z | Standardized change in task-difference mPFC inter-brain synchrony |
