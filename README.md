# Hyperbaric oxygen intervention, cooperation, and inter-brain synchrony

This repository contains analysis code and example data for the manuscript:

**Hyperbaric oxygen intervention enhances cooperative gains in high-trust people at high altitude: the role of medial prefrontal inter-brain synchrony**

## Overview

This study examined whether hyperbaric oxygen intervention modulates cooperative behavior under high-altitude hypoxic conditions, and whether such behavioral changes are associated with medial prefrontal inter-brain synchrony measured using fNIRS hyperscanning.

The repository provides code for:

1. Behavioral analysis
2. ROI-level inter-brain synchrony analysis
3. Moderation analysis involving interpersonal trust
4. ROI-specificity analysis
5. Pseudo-dyad validation
6. Figure generation

## Data availability

The raw fNIRS hyperscanning data and questionnaire data are not publicly available because they contain information from human participants and are subject to ethical and privacy restrictions.

Processed data supporting the main statistical analyses may be made available from the corresponding author upon reasonable request, subject to institutional approval.

This repository contains only example data with the same structure as the analysis datasets. The example data are provided for code demonstration purposes and do not contain identifiable participant information.
